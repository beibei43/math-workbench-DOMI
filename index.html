举一反三 · 联网出题（可选）

不开启也完全能用：默认用本机变式题库按同一题型现出新题（换数字、换情境），答案由程序算好，离线可用。开启后优先联网出题，联网失败会自动退回本机题库，不会卡住。

⚠ 密钥只保存在这台设备的浏览器里，只有点「举一反三」时才会向上面填的地址发请求（会带上原题文字）。浏览器可能因跨域限制拦住请求，失败会自动退回本机题库。AI 生成的答案请家长先核对一遍再给孩子看。不想配这些，留空即可。

数据备份（全部保存在本机）

备份为 JSON，含全部任务进度、练习记录、错题、随手录入的题目与题目图片。换设备时导入即可继续。导出备份是生成下载文件，不受上面「网页存储用量」限制；即使提示空间不足，也随时可以导出。建议把下载到的备份文件复制到 F 盘长期保存。

跨设备同步（GitHub 文件同步）

手机 / 学习机 / 网页共用同一份数据：数据存成仓库里的 sync.json，每次改动自动同步。需一次性配置 GitHub 仓库与访问令牌（步骤见聊天里的「部署与同步步骤」）。错题/随手录题的照片存在各设备本地，不同步（题目文字会同步）。

填好令牌后点「立即同步」即可把本机数据上传并建立云端备份。

部署与说明

纯静态网页，无账号、无服务器：整个文件夹上传到任意静态托管即可；也可直接双击 index.html 在电脑 / 手机 / 学习机浏览器打开。数据保存在当前浏览器的 localStorage 与 IndexedDB，换浏览器或清理缓存前请先导出备份。直接双击打开（file://）时若浏览器禁用 IndexedDB，照片会自动改存 localStorage（容量较小，建议更勤地备份）。拍照 OCR 首次需联网下载中文识别包；离线时可手动输入题目文字，原图仍会保存。题型判别是本地关键词规则，不是 AI 理解，判错时在下拉里改一下即可。
